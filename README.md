# Shelter Defence 플레이 가이드

`Shelter Defence`는 브라우저에서 플레이하는 1인칭 방어 게임입니다. 병사와 무기를 준비하고, 몰려오는 몬스터를 막아내며, 웨이브 보상과 상점 업그레이드로 더 오래 버티는 것이 목표입니다.

## 실행 방법

1. 프로젝트 의존성을 설치합니다.

   ```bash
   npm install
   ```

2. 개발 서버를 실행합니다.

   ```bash
   npm run dev
   ```

3. 브라우저에서 터미널에 표시되는 주소를 엽니다. 기본 주소는 보통 `http://127.0.0.1:5173`입니다.

## 기본 흐름

1. 시작 화면에서 `Preparation`을 누르면 상점/준비 화면으로 이동합니다.
2. `Start Game`을 누르면 현재 준비 상태로 게임을 시작합니다.
3. 전투 중에는 마우스로 조준하고, 병사들이 장착한 무기로 적을 공격합니다.
4. 웨이브를 클리어하면 Gold, Rubi, Magazine 보상을 받고 업그레이드 카드를 선택합니다.
5. 스테이지 마지막 웨이브를 클리어하면 다음 스테이지로 넘어갑니다.
6. 마지막 스테이지 이후에는 `Infinite War`에 진입할 수 있습니다.

## Preparation 화면

Preparation 화면에서는 전투 전에 병사, 무기, 터렛, 아이템을 준비합니다.

- 병사를 고용하거나 해고할 수 있습니다.
- 병사마다 무기를 선택해 장착할 수 있습니다.
- 터렛을 설치하고 강화할 수 있습니다.
- Gold로 아이템을 구매할 수 있습니다.
- Rubi로 병사, 터렛, 무기를 레벨업할 수 있습니다.
- 전투 중 `F8`을 누르면 현재 런을 유지한 채 Preparation 화면으로 들어갈 수 있습니다.

아이템 구매는 다음 방식으로 동작합니다.

- 왼쪽 클릭: 1개 구매
- 왼쪽 버튼 누르고 있기: 연속 구매
- 오른쪽 클릭: 10개 구매
- 대부분 아이템은 최대 999개까지 보유할 수 있습니다.
- Defense Vest는 현재 고용된 병사 수만큼만 구매할 수 있습니다.

## 레벨업 비용

Soldier와 Turret 레벨업 비용은 현재 레벨 구간에 따라 증가합니다.

| 현재 레벨 | 필요 Rubi |
| --- | ---: |
| LV.1-10 | 5 |
| LV.11-20 | 15 |
| LV.21-30 | 25 |
| LV.31-40 | 35 |
| LV.41-50 | 45 |

Weapon 레벨업 비용도 10레벨마다 증가합니다.

| 현재 레벨 | 필요 Rubi |
| --- | ---: |
| LV.1-10 | 10 |
| LV.11-20 | 20 |
| LV.21-30 | 30 |
| LV.31-40 | 40 |
| LV.41-50 | 50 |

레벨업 효과는 전투 능력에 반영됩니다.

- Soldier: STR, DEX, INT가 증가합니다.
- Turret: 공격력, 공격 속도, 치명타 확률, 실드 성능이 증가합니다.
- Weapon: 공격력과 공격 속도가 증가합니다.
- Anais의 STR이 오르면 Barricade 최대 체력도 함께 증가합니다.

## 아이템과 특수 공격

| 항목 | 사용 방법 | 효과 |
| --- | --- | --- |
| Defense Vest | 자동 적용 | 병사가 받는 피해를 줄입니다. |
| Health Potion | `1` | 일정 시간 동안 병사 체력을 회복합니다. |
| Agility Potion | `2` | 일정 시간 동안 공격 속도를 올립니다. |
| Intelligence Potion | `3` | 일정 시간 동안 치명타 확률을 올립니다. |
| Repair Kit | `4` | Barricade와 터렛 실드를 즉시 수리합니다. |
| Magazine | 자동 사용 | 재장전에 필요한 예비 탄창입니다. |
| Grenade | `F4` | 조준 지점 주변의 적에게 범위 피해를 줍니다. |
| Air Strike | `F5` | 화면의 모든 적에게 큰 피해를 줍니다. |

Grenade는 10초마다 1개씩 충전되고, Air Strike는 30초마다 1개씩 충전됩니다.

## 전투 화면 읽기

- 왼쪽 병사 패널에는 병사 프로필, 레벨, 체력 링, 장착 무기, 무기 레벨, 탄약, Magazine 수가 표시됩니다.
- 화면 하단에는 사용할 수 있는 아이템 수가 표시됩니다.
- 왼쪽 아래에는 Score, Gold, Rubi가 표시됩니다.
- 중앙 하단에는 Barricade 체력이 표시됩니다.
- 오른쪽에는 터렛 상태와 터렛 실드가 표시됩니다.
- 화면 위쪽에는 현재 스테이지, 웨이브, 남은 적 수가 표시됩니다.
- Infinite War에서는 웨이브 대신 생존 시간이 표시됩니다.

## 설정 메뉴

`F2`로 설정 메뉴를 열 수 있습니다.

- Sound: 사운드 켜기/끄기
- Auto Fire: 자동 발사
- Auto Targeting: 자동 조준
- Random Buff: 웨이브 클리어 업그레이드 자동 선택
- Infinite War: 마지막 스테이지 이후 Infinite War 자동 진입
- Infinite Loop: 마지막 스테이지 이후 다시 Stage 1부터 반복
- Zombie Texture: 몬스터 재질 표현 방식 변경
- Zombie/Spawn: 한 번에 생성되는 몬스터 수 조절

## Infinite War

Infinite War는 마지막 스테이지 이후 진입할 수 있는 무한 전투 모드입니다.

- 몬스터가 계속 반복해서 생성됩니다.
- 시작 난이도는 Stage 1 기준으로 시작합니다.
- 시간이 지날수록 몬스터 능력치가 점점 강해집니다.
- 보스 처치 시 Rubi를 즉시 획득할 수 있습니다.
- 오래 버틸수록 Score를 더 많이 올릴 수 있습니다.

## 보상

- 적을 처치하면 Score와 Gold를 얻습니다.
- 웨이브 클리어 시 Gold, Rubi, Magazine을 얻습니다.
- 중간 보스 처치 시 Rubi 10-20개를 즉시 얻습니다.
- 큰 보스 처치 시 Rubi 20-40개를 즉시 얻습니다.

## 처음부터 다시 시작하기

게임 중 언제든 `F12`를 누르면 전체 상태가 초기화되고 처음 화면으로 돌아갑니다. 이때 병사 고용, 아이템, 레벨, 웨이브, 점수 등 현재 플레이 파라미터가 모두 초기 상태로 돌아갑니다.
